# Food Calorie Estimation System

This project is a machine learning-based system designed to estimate the calorie content of food items. Using a dataset of food items and their calorie values, the system predicts the calorie count for a given food name entered by the user. It leverages a `RandomForestRegressor` model for accurate predictions.

---

## **Features**
- **Data Preprocessing**: Cleans the dataset by handling missing values and converting data into a usable format.
- **Machine Learning Model**: Uses `RandomForestRegressor` for calorie prediction with high accuracy.
- **Interactive Input**: Allows users to input a food name and provides real-time calorie estimation.
- **Visualization**: Generates visualizations of data distribution for better understanding.

---

## **Technologies Used**
- **Python**: Core programming language for implementation.
- **Libraries**: 
  - `pandas` for data handling.
  - `scikit-learn` for machine learning and preprocessing.
  - `matplotlib` for data visualization.
  - `numpy` for numerical operations.
